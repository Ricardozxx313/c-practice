# c-practice

手写 C 语言练习仓库。2026 年 11 月起，每天一个程序，不借助 AI 生成代码。

## 目标

用 21 天把「能看懂 C 代码」练成「能关掉资料默写 C 代码」，
为嵌入式岗位面试的白板手写做准备。

## 目录

- `week1/` — 基础语法（变量、printf/scanf、分支、循环、数组、函数）
- `week2/` — 指针、字符串、函数指针、const 与指针
- `week3/` — 结构体、位操作、内存管理、环形缓冲区
- `notes/` — 错误本（每天的错题、原因、正确写法）
